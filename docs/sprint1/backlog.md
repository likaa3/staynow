**Спринт:** 1 «Продукт і вимоги»

**Команда:** Team B

**Автор:** Євгенія Гетьман, Тест-аналітик


**Норматив для команди з 5 осіб:** ≥15 user stories (у беклозі - 17)

## Склад аркушів

| Аркуш | Що містить |
|---|---|
| Беклог | User stories US-01…US-17 за шаблоном «Як (роль), я хочу (…), щоб (…)»: ID, роль, бажання, мета, пріоритет, примітки для тестування, статус |
| Очікування → stories | Простежуваність: шість очікувань замовника (E1-E6, замовлення «Сезонні тарифи та політика скасування») → ролі → історії, що їх покривають |

## Пріоритети

- **High** - без цього функція не має сенсу для замовника
- **Medium** - важливо, але можна відкласти на наступний реліз
- **Low** - доповнення

## Статуси

чернетка → затверджено після рецензії Скрам-майстра (відповідність шаблону) та Аудитора-опонента (покриття очікувань).
