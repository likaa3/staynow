## 5. Висновок

Проєкт відтворюється «з нуля» за README на машині, де його раніше не було, без змін коду і без підказок авторів: `mvn clean test` → 130 / 17 F / 1 E, повний набір з UI → 141 / 17 F / 1 E, двічі поспіль однаково. Ті самі цифри отримав Чаплюк Д. на своїй машині. Усі 18 не зелених запусків - червоні тести закладених дефектів BUG-M01…M06, кожен має звіт, Issue і ID у коментарі тесту; неочікуваних падінь немає. Норматив команди з 5 осіб виконано повністю. Головну проблему спринта - UI-тести на самописній сторінці замість demo продукту - виправлено до здачі. Відкритими лишаються дрібні зауваження № 16-18.
